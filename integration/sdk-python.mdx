From Python you need two things, and neither requires a Velobase-specific
package:

- **Model calls**: point the official OpenAI SDK at the gateway. See
  [OpenAI-Compatible Gateway](/integration/openai-compatible).
- **Billing control-plane** (deposits, balances, freeze / consume / deduct):
  call the REST endpoints directly with `requests`, `httpx`, or any HTTP
  client.

<Note>
A `velobase-billing` package exists on PyPI, but it is outdated and does not
track the current API. Prefer the REST calls below. If you are on Node, the
[JavaScript SDK](/integration/sdk-javascript) (`@velobaseai/billing@^1.2.0`) is
the maintained, typed client.
</Note>

## Model calls (OpenAI SDK)

```python
from openai import OpenAI

client = OpenAI(
    api_key="vb_live_your_project_key",
    base_url="https://api.velobase.io/v1",
    default_headers={"X-Velobase-Customer": "user_123"},
)

resp = client.chat.completions.create(
    model="your-model-id",  # one of your project's models, see GET /v1/models
    messages=[{"role": "user", "content": "Hello!"}],
)
print(resp.choices[0].message.content)
```

## Deposit credits to a customer

`amount` is a positive integer number of credits. 1 credit = 1 micro-USD, so
1 USD = 1,000,000 credits.

```python
import requests

BASE = "https://api.velobase.io"
HEADERS = {"Authorization": "Bearer vb_live_your_project_key"}

resp = requests.post(
    f"{BASE}/v1/customers/deposit",
    headers=HEADERS,
    json={
        "customer_id": "user_123",
        "amount": 5_000_000,  # $5.00
        "idempotency_key": "stripe_evt_1a2b3c",  # so a retry never double-credits
    },
)
resp.raise_for_status()
```

## Read a balance

`GET /v1/customers/{id}` returns the customer with their wallets, each broken
down by source:

```python
cust = requests.get(f"{BASE}/v1/customers/user_123", headers=HEADERS).json()
wallet = cust["wallets"]["credits"]
print(wallet["available"], "available")
for s in wallet["sources"]:
    print(s["source"], s["available"])
```

## Read the ledger

```python
page = requests.get(
    f"{BASE}/v1/customers/user_123/ledger",
    headers=HEADERS,
    params={"limit": 20},
).json()
```

Paginate with the returned cursor; filter with `operation_type` or
`transaction_id`.

## Billing primitives

For metering work you price yourself (not model calls, which bill
automatically), use freeze → consume for unknown-cost work, or deduct for
fixed-cost work. All amounts are integer credits.

```python
# Known cost up front: 200,000 credits = $0.20
requests.post(f"{BASE}/v1/billing/deduct", headers=HEADERS, json={
    "customer_id": "user_123", "transaction_id": "img_001", "amount": 200_000,
})

# Unknown cost: reserve a budget, then settle the actual amount.
requests.post(f"{BASE}/v1/billing/freeze", headers=HEADERS, json={
    "customer_id": "user_123", "transaction_id": "job_001", "amount": 1_000_000,
})
requests.post(f"{BASE}/v1/billing/consume", headers=HEADERS, json={
    "transaction_id": "job_001", "actual_amount": 730_000,  # releases the rest
})
# To cancel instead: POST /v1/billing/unfreeze {"transaction_id": "job_001"}
```

## Errors

All failures return a structured `error` object with `message`, `type`, and a
stable `code`. See [Errors](/advanced/errors).
